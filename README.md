# BizPilot Lite · CEO 经营驾驶舱（开源教学版）

《给 CEO 的 AI Coding 课》配套开源项目：一个可导入企业数据、发现经营异常、生成 AI 经营分析的**通用经营驾驶舱**框架。

> 不需要成为程序员，也能借助 AI，把经营指标、企业数据和管理逻辑做成可运行的软件。

- 技术栈：Next.js 14（App Router）+ TypeScript + Tailwind CSS + Supabase
- 当前为教学骨架（第 1 篇已发布配套），使用 `lib/metrics.ts` 中的**脱敏模拟数据**即可运行，无需配置数据库
- 开源协议：MIT

## 它解决什么问题

经营数据散落在 Excel、ERP、CRM、财务系统里，每月靠人手拼报表；老板看到的是"数据"，不是"哪里出了问题"。

BizPilot Lite 的数据流：

```
Excel / API / 人工填报
        ↓
   统一经营指标
        ↓
 CEO 经营驾驶舱
        ↓
异常提醒 / AI 分析 / 行动建议
```

企业后续只需继续接入数据、配置指标、增加模块，不必重新开发整个系统。

## 快速开始

```bash
npm install
npm run dev
# 打开 http://localhost:3000
```

未配置 Supabase 时，首页与四大模块直接使用模拟数据。配置后（`cp .env.example .env.local`）可切换为真实数据。

## 四大经营模块

| 模块 | 关注什么 | 典型指标 |
| --- | --- | --- |
| 经营结果 | 钱进来了吗、赚到了吗 | 收入、成本、毛利、利润、现金流、目标完成率 |
| 客户增长 | 客户在涨还是流失 | 新增/活跃/流失客户、客单价、复购率、客户集中度 |
| 项目与交付 | 承诺能兑现吗 | 项目进度、预算偏差、延期风险、交付质量 |
| 组织效率 | 人用对了吗 | 人均产出、费用率、团队负载、关键岗位风险 |

## 课程与分支

本仓库是《给 CEO 的 AI Coding 课》的配套代码。系列共 8 篇，逐篇从"经营想法"走到"部署上线的完整驾驶舱"：

1. CEO 为什么应该学 AI Coding（需求卡）
2. 先别写代码，先让 AI 帮你拆需求（PRD / 数据字典 / 验收标准）
3. 用 AI 搭出第一版经营驾驶舱（首页 + 四大模块 + 模拟数据）
4. 先设计数据，再接真实业务（统一经营指标模型）
5. 让企业把自己的数据填进来（Excel / 人工 / API 适配层）
6. 让驾驶舱发现问题，而不是只展示数据（规则引擎 / 异常）
7. 给经营驾驶舱装上 AI 大脑（AI 经营分析 / 日报）
8. 部署上线，让驾驶舱真正进入经营会议（登录 / 权限 / 备份 / 部署）

`main` 分支展示当前最新版本；每篇课程的对应版本会随文章发布逐步补齐。

## 与内部 BizPilot 的关系

内部 BizPilot 是一套真实运行过的企业系统（Vue 3 + Go），作为本课程的**私有验证场**；BizPilot Lite 是其脱敏、重写的**公开教学版**，承载统一的经营模型与课程实践。本仓库不含任何内部业务数据或真实账号。
