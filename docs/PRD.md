# 产品需求文档（PRD）· 经营驾驶舱 MVP（课程第 2 篇产出）

> 由 AI 根据「需求卡」扩写而成。结构遵循：目标 / 用户 / 场景 / 功能 / 数据来源 / 业务规则 / 验收条件 / 暂不实现。

## 1. 目标
让一位不懂编程的 CEO，在一天内拥有一个可运行的经营驾驶舱原型，并能逐步接入自己的企业数据。

## 2. 用户
- 主用户：CEO / 业务负责人（非技术）
- 协作者：财务、销售、项目负责人（提供数据与确认口径）

## 3. 使用场景
- 每周经营会议前，打开驾驶舱看一眼核心指标。
- 发现某指标红黄绿异常，追到责任人与建议动作。
- 让 AI 基于数据生成一份 CEO 日报。

## 4. 功能（MVP）
- 驾驶舱首页：四大模块入口 + 经营结果指标卡片 + 收入/利润/现金流趋势图
- 模块详情页：各模块指标卡片
- 指标字典：编码 / 名称 / 口径 / 单位 / 负责人
- 模拟数据跑通（无需数据库）

> 第一版具体指标与页面清单见 `数据字典.md`（四大模块指标 + 页面路由）。

## 5. 数据来源
- 第一版：Excel / CSV 导入、人工填报、示例模拟数据
- 进阶：CRM / ERP / 财务系统 API（统一适配层，第 5 篇）

## 6. 业务规则
- 指标统一结构：`{ code, name, caliber, actual, target, yoy, mom, source, owner }`
- 红黄绿：达成率 ≥100% 绿；80%–100% 黄；<80% 红（「越低越好」类指标反向判断）
- AI 只做分析，不直接改数据；结论须引用指标与数值

## 7. 验收标准
- [ ] `npm run dev` 能启动，首页正常渲染
- [ ] 四大模块均可点击进入并显示指标
- [ ] 指标卡片显示当前值、目标、同比、环比、负责人
- [ ] 趋势图展示收入/利润/现金流近 5 期
- [ ] 指标字段符合 `数据字典.md` 的统一契约（每条含编码/名称/口径/当前值/目标值/同比/环比/来源/负责人）
- [ ] 红黄绿状态正确（达成率≥100% 绿、80%–100% 黄、<80% 红；"越低越好"类指标反向判断）
- [ ] 全部为脱敏模拟数据，不含任何真实企业账号与业务数据

## 8. 暂不实现（未来版本）
- 真实 OAuth 接入（巨量/京东等）
- 多企业租户与复杂权限
- 自定义报表引擎
- 移动端适配
