## 贯穿项目

```
API 接口 / Excel 导入 / 人工填报
                ↓
          统一经营指标
                ↓
      CEO 企业经营驾驶舱
                ↓
    异常提醒 / AI 分析 / 行动建议
```

企业后续只需要继续接入数据、配置指标和增加模块，不必重新开发整个系统。

## 配套代码

本系列配套可运行项目在仓库 `lite/`（Next.js + Supabase）。每篇对应一个 Git 分支（`01-intro` … `08-deploy`），读者可逐篇对照复现。
