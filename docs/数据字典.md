# 数据字典 · 经营驾驶舱（课程第 2 篇产出）

> 本文件是「统一经营指标模型」的字段契约 + 第一版指标清单 + 页面清单。
> 它是整个驾驶舱的"地基"：不论数据来自 Excel、ERP 还是人工填报，都先变成这里定义的统一结构，驾驶舱才认。
> 字段与 `lite/lib/metrics.ts` 中的 `Metric` 类型一一对应（已验证可运行）。

---

## 1. 指标字段契约（每条指标必须包含）

| 字段 | 含义 | 类型 / 示例 |
| --- | --- | --- |
| `metric_code` | 指标编码（系统唯一标识） | 字符串，`monthly_revenue` |
| `metric_name` | 指标名称 | 字符串，`月度收入` |
| `module` | 所属模块 | `business` / `customer` / `project` / `org` |
| `period` | 统计周期 | 字符串，`2026-07` |
| `actual_value` | 当前值 | 数字，`1280000` |
| `target_value` | 目标值 | 数字，`1500000` |
| `yoy` | 同比 | 数字（比率），`0.12` 表示 +12% |
| `mom` | 环比 | 数字（比率），`-0.03` 表示 -3% |
| `unit` | 单位 | `CNY` / `count` / `pct` |
| `source` | 数据来源 | `erp_api` / `crm_api` / `manual` 等 |
| `owner` | 负责人 | 角色名，`销售负责人` |
| `updated_at` | 更新时间 | 日期，`2026-08-01` |
| `trend` | 近 N 期数值（可选，仅用于趋势图） | 数字数组，`[110,118,121,125,128]` |

> 说明：指标的**统计口径**（如"收入是否含税""利润是否含非经营性损益"）是经营对齐的关键。代码中未单列 `caliber` 字段，建议在 `metric_name` 或后续"指标说明"中写清口径，避免不同部门对同一指标理解不一致。

**颜色规则（红黄绿）**：达成率 = `actual_value / target_value`；"越高越好"类指标 ≥100% 绿、80%–100% 黄、<80% 红；"越低越好"类指标（如成本、流失率、风险）反向判断。详见 `metrics.ts` 的 `metricStatus()`。

## 2. 第一版指标清单（四大模块）

### 经营结果（business）
| 编码 | 名称 | 单位 | 来源 |
| --- | --- | --- | --- |
| `monthly_revenue` | 月度收入 | CNY | erp_api |
| `gross_profit` | 毛利 | CNY | erp_api |
| `net_profit` | 经营利润 | CNY | erp_api |
| `cash_flow` | 现金流 | CNY | erp_api |
| `total_cost` | 总成本 | CNY | erp_api |
| `target_rate` | 目标完成率 | pct | manual |

### 客户增长（customer）
| 编码 | 名称 | 单位 | 来源 |
| --- | --- | --- | --- |
| `new_customers` | 新增客户 | count | crm_api |
| `active_customers` | 活跃客户 | count | crm_api |
| `churn_rate` | 客户流失率 | pct | crm_api |
| `arpu` | 客单价 | CNY | crm_api |
| `repurchase` | 复购率 | pct | crm_api |
| `concentration` | 客户集中度 | pct | manual |

### 项目与交付（project）
| 编码 | 名称 | 单位 | 来源 |
| --- | --- | --- | --- |
| `project_progress` | 项目进度 | pct | project_api |
| `budget_deviation` | 预算偏差 | pct | project_api |
| `delay_risk` | 延期风险 | pct | project_api |
| `delivery_quality` | 交付质量 | pct | project_api |

### 组织效率（org）
| 编码 | 名称 | 单位 | 来源 |
| --- | --- | --- | --- |
| `per_capita_output` | 人均产出 | CNY | hr_api |
| `expense_rate` | 费用率 | pct | erp_api |
| `team_load` | 团队负载 | pct | hr_api |
| `key_role_risk` | 关键岗位风险 | pct | manual |

> 以上均为**脱敏模拟数据**，不来自任何真实企业，仅用于教学跑通。

## 3. 页面清单（第一版 MVP）

| 页面 | 路由 | 内容 |
| --- | --- | --- |
| 驾驶舱首页 | `/` | 四大模块入口 + 核心指标卡片 + 收入/利润/现金流趋势图 |
| 模块详情 | `/modules/[key]` | 单模块指标卡片 + 完成率/状态 |
| 指标字典 | `docs/数据字典.md` | 字段契约 + 指标清单（本文件） |

> MVP 边界：第一版只做"展示指标 + 趋势 + 红黄绿状态"，**不实现**复杂权限、AI 分析、真实账号接入（见 PRD「暂不实现」）。

## 4. 与 PRD 的关系

- `docs/PRD.md`：讲"为什么做、给谁用、做什么、不做什么"（产品视角）。
- 本文件：讲"指标到底是什么样、看哪些、页面有哪些"（数据结构视角）。
- 两者共同构成第 2 篇的交付物，供第 3 篇"搭出第一版原型"直接使用。
